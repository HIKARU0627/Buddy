- X11: スナップショットと購読の間で更新し、受領した cursor の反映前に接続を失わせます。中枢だけを再起動し、イベントを再配信・重複・逆順で渡します。双方の表示が最新へ収束し、古い状態で上書きされず、変更は 1 回のままであることを確認します。
