## 判定（下書き）

**模擬の範囲では B03 の完了条件 3 つの根拠と試験がそろった。実機の確認はすべて未実施のため、B03 は未完了とする。** 2 台目以降の承認・失効の手段は B03-06（ADR 0026）で入った。実機の 2 台の確認（device-check の D・E）の前に、自宅の登録の手段が要る。

## 残ること（B03 の外・判断待ち）

- 自宅の登録の UI か CLI（実機の 2 台の確認の前提）。ペアリングの開始・申請の承認と拒否・端末の失効は B03-06（#74）で入った。
- 失効を中枢の画面だけに限る経路の変更（#75）。
- 実機の確認と `tests/integration/evidence-b03-<端末>.json` の記録。
- `tests/test-map.json` の product_test は X04・X11・X42 を含めて not_run のまま（製品の統合試験の合格ではない）。
- 承認の UI と preview の発行・表示の切替・リース（B04・B05）、来客モード・全体停止の解除。
