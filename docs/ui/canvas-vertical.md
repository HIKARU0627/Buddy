# UI-03 最小の縦断の記録（入力バー → 流れ → 模擬の配置者 → 用事のカード 1 枚）

[ADR 0032](../adr/0032-ui-canvas-stream-and-window-roles.md) の最小の縦断（Issue #95、親 #92）の記録です。**製品の試験の合格ではありません。** 既定のデスクトップは今の 1 つの窓のままで、開発用のフラグ（`--buddy-ui=canvas`）のときだけ流れへ送ります。

記録は 3 つに分けます。

- **模擬**: Electron を起動しない試験（`pnpm test`）。127.0.0.1 の Core と main の部品の統合を含む。
- **実機相当の確認**: この Mac で、自分で起動した Core と Electron を本物の経路で通し、ページを CDP で撮った（OS の窓の撮影ではない）。
- **未実施**: 確かめていないこと。

## 作ったもの

[ADR 0032 の「UI-03 の最小の縦断」](../adr/0032-ui-canvas-stream-and-window-roles.md)を参照。場所は `apps/core/src/canvas-stream.ts`、`apps/desktop/src/main/canvas-bridge.ts`、`apps/desktop/src/renderer/screens/canvas/`。契約は `GET /v1/canvas`（`getCanvas`）、購読の canvas の知らせ（`EventStreamMessage`）、通知 `desktop.canvas_changed`（`DesktopCanvasView`）。

## 実機相当の確認（macOS 27.0.1、Electron 44.9.0、2026-10-23）

自分で起動した Core（模擬の鍵・provider）と、`--buddy-ui=canvas` の Electron（模擬のキーチェーン、一時の userData）を、本物の経路で通した。ペアリングは従来の窓（3 つの窓の試作にはペアリングの画面がまだない。UI-04）で済ませた。入力バーに文字を打って Enter を送り、キャンバスの窓にカードが出ることを確かめた。ページの撮影は CDP の `Page.captureScreenshot`（描画だけ。画面共有から守る設定は変えていない）。スクリーンショットはスクラッチの場所（リポジトリには入れない）。

- 接続直後に版 0 の空の記述を取り、発言の後に版 1 のカード（5 件の行・強調の枠）が出た。ライト・ダークの両方で撮った。
- 入力バーは送信後に欄が空になった。
