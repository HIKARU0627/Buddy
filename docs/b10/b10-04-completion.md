## 守ること（Issue の「守ること」との対応）

| 守ること                             | 担保                                                                                                                                                                                               |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 読み上げる文はコードの定型文だけ     | つなぎ・背景化・受付・完了・聞き返しはすべて domain の定型文（`voice-commentary.ts`）。モデルの返答文は雑談・一般の質問の文字入力だけに限る（U217）。相談の受付でも使わない（AT「U217/U560…」）    |
| 実行を確認できないまま完了を言わない | 完了の文は実行の確認（`executed` が真）があるときだけ（VCL「commentary: completion is told only when the execution is confirmed…」）。相談・調査の受付の文は「受け付けました」で、完了とは言わない |
| 音声の「はい」を承認にしない         | 承認は画面の承認だけ（意図表の `approval`、ADR 0004・0005）。この作業では承認の経路を変えていない                                                                                                  |
| 結果不明の外部変更を自動再送しない   | 受付器の例外は受け付けていない側に倒し、自動で再送しない（AT「U254: when the acceptor is unavailable or fails…」「U560: when the consult acceptor is unavailable…」）                              |
