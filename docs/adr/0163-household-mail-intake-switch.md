# ADR 0163: 利用通知の取り込みを止める手段（家計簿 段階 1 の一部）

- 日付: 2026-11-26
- 状態: 家計簿の段階 1 の部分。ADR 0160 で「Gmail の接続があれば本人の操作なしに取り込みを始める」（U326 の暫定）とした取り込みを、本人が家計簿の画面から止める・再開できるようにする。**模擬の試験だけ**で、実在のメール・実機での確かめは未実施。
- 根拠: 本人の依頼（本人の手間を減らし、できるだけ早く取り込む）と、ADR 0160 の U326 の残り（止める手段は画面を作るときに決める）。ADR 0003・0158・0160・0161・0162。
- 対象: マイグレーション 0018、`packages/storage/src/household-store.ts`（`household.settings_get`・`household.settings_set`、`household.mail_pending` の止めている間の扱い）、`apps/core/src/household-mail-intake.ts`・`api-household.ts`、`packages/contracts`（`HouseholdSettings`・`HouseholdSettingsChangeRequest`・`POST /v1/household/settings`、`HouseholdOverview.settings`、IPC の `desktop.household_intake`、`DesktopHouseholdView.mail_intake`）、`apps/desktop`（`HouseholdBridge.intake`・画面の取り込みの行）。

## 決めたこと

| 対象         | 決定                                                                                                                                                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 置き場所     | 1 行だけの表 `household_settings`（取り込みの入・切と、1 ずつだけ進む版）。行がなければ入・版 0。本人の決定なのでバックアップに含める                                                                                                    |
| 止めている間 | 保存層の `household.mail_pending` が同じ transaction で設定を読み、止めていれば何も返さず、取り込みの基準も作らない。Core の取り込みは `intake_off` で飛ばす（メールの見出しも読まない）                                                 |
| 再開         | 切から入へ戻すとき、口座ごとの取り込みの基準を消す。次の取り込みでその時点の同期済みのメールをすべて確かめ済みにし、止めていた間に届いたメールは読まない（U334）。欠けた分は書き出しの取り込みで補う                                     |
| API          | 今の設定は月ごとの合計（`GET /v1/household/months`）の `settings` で返す。変更は `POST /v1/household/settings`（本人の画面操作だけ）。版が違えば 409、成否不明は 503                                                                     |
| 版の型       | `HouseholdSettingsRevision`（ADR 0003 の共通の 10 進の形。まだ変えていなければ 0）                                                                                                                                                       |
| 画面         | 家計簿の欄の頭に「カードの利用通知メールを取り込んでいます／取り込みを止めています」と、「取り込みを止める／再開する」のボタン。止めている間は、再開しても止めていた間の通知は読まないことを書いておく。読めていなければ入・切を出さない |
| 端末の経路   | IPC の `desktop.household_intake`（ロック解除済みの画面操作）。設定の版は main が持ち、画面へは入・切だけを渡す。今と同じ値は送らない。拒否・結果不明は送り直さずに読み直す                                                              |

## 原本に決めがない項目

- U326: 取り込みを始める操作（暫定 (a) のまま。止める手段をこの ADR で足した）。
- U334: 止めていた取り込みを再開したときのメール。

## 試験（模擬だけ）

- `packages/storage/src/household-store.test.ts`: 行がないときの入・版 0、止めている間に返さない・基準を作らないこと、再開で基準を作り直すこと、古い版の拒否、形の誤り、版を飛ばす更新と 2 行目を DB が拒否すること。
- `packages/storage/src/migrations.test.ts` ほか: DB の版 18、STRICT の表 62。
- `apps/core/src/household-mail-intake.test.ts`: 止めている間はメールを読まず、再開の後は止めていた間のメールを読まずに新しいメールだけを記録すること。
- `apps/core/src/api-household.test.ts`: 月ごとの合計の設定、止める・再開・古い版と再送の 409・不正な値の 422・成否不明の 503。
- `apps/desktop`: 橋渡し（読んだ版で送る・同じ値は送らない・409 と結果不明）、画面の状態（入・切の送り方と読み直し）、欄の表示。`desktop-ipc-cases.json` に受付 3 件。

**模擬の期待値だけ**。実在のメール・実機は未実施で、合格扱いにしない。

## 残ること

- 外部の家計簿サービスの書き出しの取り込み（止めていた間・初回より前の分を補う）。
- U326・U334 の本人の確認。
