# ADR 0126: B12-02 出典の永続形と URL の扱い（Brave の利用条件との整合）

- 日付: 2026-11-14
- 状態: B12-02（親 #27、Issue #264）の P1。**URL は永続保存しない（本人の決定 A、2026-11-14。U183・U290 を解決）**。実 API は呼んでいない。法務確認・Brave への書面確認は未実施。
- 根拠: Brave Search API Terms of Use（Last updated 1 Sep 2026。公式ページ。2026-11-14 に読み直した）、`docs/b12/search-service-comparison.md`、設計 05「公開Web調査」（「検索結果と根拠の短い抜粋、取得時刻、URL を対応させます」）、本人の決定（2026-11-03、D2）、ADR 0077。
- 対象: `packages/contracts/schemas/buddy.schema.json` の `WebSourceRecord`・`WebTransientLink`・`WebTransientLinks`、`packages/domain/src/web-research-status.ts` の `webSourceRecordErrors`。

## 利用条件（確認した条文）

| 条                      | 内容                                                                                                                                    |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 1(j) Search Results     | API 呼出しの**全出力**（internet search results・Generated Results・Third-Party Content）                                               |
| 3(b)(i)                 | Search Results の全部または一部の保存・キャッシュ・データベース化を禁止。例外は「Customer Applications の動作に必要な一時的な保存」だけ |
| 3(b)(ii)・(xii)・(xiii) | 派生物の作成・再配布・AI モデルの作成・評価・訓練・微調整・ベンチマーク等への利用を禁止                                                 |
| 契約の終了後            | Search Results の保持を禁止し、全複製を消去する義務（13(c)(ii)。Order Form に別の定めがあればそれに従う）                               |
| 「URL」の語             | 規約本文に無い。URL だけを別扱いする条文は無い                                                                                          |
| 料金ページの FAQ        | 「結果の保存・モデル訓練に使えるか」→「Yes, with a custom plan」。通常の Search／Answers プランに保存権は書かれていない                 |

条番号の細部（3(b) の終盤の (xiv)・(xv) の割り当て）は、読み取りに揺れがあった。条文を契約・申請に引く前に、原文の番号を目で確かめ直す。比較表の「3.2(i)」「3.2(xiii)」は 3(b)(i)・3(b)(xiii) が正しいので直した。

## 決めたこと

| 対象               | 決定                                                                                                                                                                                                                                                                                                                          |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 永続の出典         | `WebSourceRecord`。**自分で取得した本文（`page_read`）から作った**短い抜粋（500 文字以内）・要約（4000 文字以内）・取得時刻・本文の hash（64 桁の 16 進）・検索語との対応（`query_id`）・自分で取得したページの title だけを持つ。検索結果のタイトル・スニペット・要約・順位・件数を持たない（`additionalProperties: false`） |
| 検索要約だけの出典 | 永続の形に入れない（`basis` は `page_read` だけ）。その場の表示にも使うだけで、保存しない。#258 の `WebResearchSource`（`search_summary_only` を持つ）は、**その場の表示用**の形として残す                                                                                                                                    |
| URL の既定         | **保存しない**。`WebSourceRecord.url` は `WebUsagePolicy.url_storage` が `allowed` のときだけ非 null にできる。`undecided`・`disallowed` では持てず、`webSourceRecordErrors` が `url_not_storable` を返す。応答全体の検査（`webResearchStatusErrors`）にも含め、URL を持つ完了を `unconfirmed` にする                         |
| その場の表示       | `WebTransientLinks`（`retention: 'transient_only'`、5 件まで）。URL とタイトルは、応答の `transient_links` だけに載せ、`result` には載せない。中枢のメモリの中だけに置き、データベース・イベントの記録・ファイル・キャッシュに書かない。再起動や表示の後に無くなってよい。**保存する形（B12-05 の保存の行）には含めない**     |
| たどれること       | 保存した抜粋・要約・取得時刻・検索語・本文の hash で「何をいつ読んだか」は追える。同じページを後で開き直すことは、URL を保存しない間はできない（本人の決定 A。B の許可が出るまでは変えない）                                                                                                                                  |
| 本人が貼った URL   | 本人が自分で指定した URL は検索結果ではないので、この制限の対象にならない（保存してよいかは本人指定の調査の設計で決める。この ADR は検索結果に由来する URL だけを扱う）                                                                                                                                                       |
| 訓練・評価         | 検索結果と取得本文は、回答の根拠にだけ使い、モデルの訓練・評価・改善に使わない（3(b)(xiii)。ADR 0077 の `model_use: grounding_only`）。評価セット（B10-07）に検索結果・取得本文を入れない                                                                                                                                     |

## 選択肢と本人の決定（2026-11-14: A）

| 案  | 内容                                                                | 影響                                                                                                         |
| --- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| A   | URL を保存しない（既定）                                            | 契約・実装が単純。後から同じページを開く操作はできない。設計 05 の「URL を対応させる」を一部変える判断になる |
| B   | URL だけ保存し、Brave に書面で許可を取る（custom plan／Order Form） | 契約・費用・時間。許可が出るまでは A。許可後は `url_storage` を `allowed` にするだけ                         |
| C   | 規約の解釈を本人が引き受けて保存する                                | アカウント停止と、終了時の消去義務の危険。非推奨                                                             |
| D   | 保存権のある別サービスへ替える                                      | D2 の取り直し                                                                                                |

**本人の決定（2026-11-14）: A（保存しない）。** 出典は、自分で取得した本文の抜粋・要約・取得時刻・検索語で作り、URL・タイトルはその場の表示だけにする。

- 契約の値: `WebUsagePolicy.url_storage` の決定後の値は `disallowed`。`allowed` にしない。`undecided` は決定前の値で、**`disallowed` と同じく URL を持てない**扱いのまま残す（失敗側に閉じる。既存の試験・fixture は変えない）。
- B（Brave の書面許可）と C・D は採らない。B の許可が取れた場合に広げるのは、新しい本人の決定と ADR の更新があるときだけで、このときは `url_storage` を `allowed` にし、`WebSourceRecord.url` を保存してよい。
- 設計 05 の「URL を対応させる」は、出典の抜粋・取得時刻・検索語・本文の hash で対応させる読みに変える（設計判断の変更として本人の決定を根拠に記録する。設計の原本は更新しない）。URL・タイトルの表示は B12-05 の画面（その場の表示）で扱う。

## 原本に決めがない項目

- 設計 05 は URL・抜粋・取得時刻を対応させると書くが、検索サービスの規約が保存を制限する場合の扱いは書かれていない（設計 05 は検索サービスを比較してから決めるとしていた）。URL を保存しない場合の表示（取得時刻と抜粋と検索語で足りるか）は、本人の判断と B12-05 の画面で決める。
- 抜粋の長さ 500 文字は、設計の「短い抜粋」を数にしたもの。B11-01 の根拠の抄録（200 文字）より長いのは、要約の根拠として使うため（U294、暫定）。

## 試験（模擬だけ）

- `scripts/web-research-status.test.mjs`: 永続の出典に検索結果の欄が無いこと、`undecided`・`disallowed` で URL を持てず `allowed` でだけ持てること、`transient_links` が結果の外にあること、検索要約だけの出典が形式で拒否されることを検査した。
- 規約の解釈・Brave への書面確認・URL を保存した場合の消去は、いずれも未実施。

## 残ること

- B（Brave の書面許可）は問い合わせない。許可で保存を広げたくなったときは、新しい本人の決定を待って ADR を更新する。
- 帰属表示の文言とロゴ（U184、B12-05）。
- 保存の行・保持・忘却の扱い（B12-05）。検索結果の一時保持が本当にメモリの中だけであることは、B12-03・B12-05 の試験で確かめる。
