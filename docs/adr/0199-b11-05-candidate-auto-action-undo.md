## 候補を消すときの結び付きの扱い（確かめたこと）

候補が消える経路は 3 つある。いずれも候補の行（と題・抄録の封筒・由来の辺・配信の記録）だけを消し、操作の記録（`operations`・`operation_versions`・`approvals`・`auto_actions`・`undo_records`・`request_entity_operations`）は消さない。操作の記録は操作の保持の期限（90 日。ADR 0040 の手順 5）で消える。

| 経路                                                           | 候補                                                   | 操作の記録        | 承認の行の `candidate_id`        |
| -------------------------------------------------------------- | ------------------------------------------------------ | ----------------- | -------------------------------- |
| 閉じた候補の 97 日の掃除（`candidate.sweep`）                  | 行ごと消える                                           | 残る              | 残る（どの候補にも当たらない値） |
| 明示的な忘却（`deleteForgetNode` の閉包）                      | 行ごと消える                                           | 残る（下の U641） | 残る（同上）                     |
| 期限（発言の由来の期限。ADR 0118。忘却と同じ削除の関数を通る） | 行ごと消える                                           | 残る              | 残る（同上）                     |
| 依頼の期限（ADR 0118 の U280）                                 | 消えない（依頼の参照だけ外す）。`operation_ids` は残る | 残る              | 残る                             |

- 承認の行の `candidate_id` は外さない（U642）。0015 の trigger が 7 列の変更を断り、送出直前の照合（`dispatchGuardReasons`）は `candidate_id` が空でないことを「候補を起点にした自動承認」の印にしている。外すと照合を素通りする。候補が消えた後も、照合は承認の行の依頼の版で行う（依頼の取消で適用を断ることを試験で確かめた）。
- 残る値は、作るたびに乱数で作る候補 ID（UUID v4。通知キーや本文から作らない）と依頼・関連解析の ID と版だけで、題・抄録・本文・通知キーは承認の行に無い。候補の行が消えた後、この ID から候補の内容へはたどれない。同じ通知キーで作り直した候補は新しい ID なので、古い操作が結び付かない（試験で確かめた）。
- 自動実行の一覧（`AutoActionList`）と気づきの画面は、候補 ID を返さない。気づきの画面は、候補が一覧にある間だけ、その行の中で操作を見せる。
- 忘却の台帳が記録するのは元情報（HMAC）・発言・記憶（`LedgerSource` の 3 種）で、候補 ID は記録しない。承認の行の候補 ID と台帳を突き合わせて、忘れた候補をたどることはできない。
- 候補を起点にした自動実行の操作の確定内容（用事の題・下書きの本文）は、候補・元のメールへの派生の辺（`derivations`）を持たないので、元のメールや候補を忘れても忘却の閉包に入らず、操作の保持の期限まで残る（U641）。これはこの作業より前からの扱いで、ここでは変えていない。**本人の確認を急ぐ項目**（忘れたメールの文が、自動で作った用事・下書きの確定内容として最長 90 日残る）。

## 残ること

- U640〜U643 の本人の確認（U641 は急ぐ）。
- 次のマイグレーションで `approvals.candidate_id` の索引を足す（U643）。
- 自動実行の一覧の外の操作（実行中・失敗・止まった）の状態を気づきの欄で出すか（U640 の (b)）。
- 候補を起点にした自動実行の操作の確定内容の系譜（U641）。
- 実機（macOS・Windows）での気づきの欄の見た目と取り消しの動き。
