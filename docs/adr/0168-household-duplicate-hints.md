# ADR 0168: 重なっていそうな記録の知らせ（家計簿 段階 3 の一部）

- 日付: 2026-11-26
- 状態: 家計簿の段階 3 の部分（突き合わせによる二重の登録の防止のうち、本人に知らせる部分）。同じ利用が二つの出所から記録されたかもしれない記録に、家計簿の欄で印を付ける。消すかどうかは本人が決め、自動では消さない。**模擬の試験だけ**で、実データ・実機は未実施。
- 根拠: 本人の決定（段階 3: 突き合わせによる二重の登録の防止）、ADR 0158・0162・0164・0167。
- 対象: `packages/domain/src/household-duplicates.ts`、`apps/desktop`（画面の状態の `duplicateRefs` と欄の印）。契約・API・マイグレーションは変えない。

## 決めたこと

| 対象           | 決定                                                                                                                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 同じ組         | 向き・利用した日・金額が同じ記録                                                                                                                                                                 |
| 重なっていそう | 組の中に出所の種類（利用通知・書き出し・手入力）が違う記録があるか、手入力が二つ以上ある組。利用通知だけ・書き出しだけの組は、別々の通知・別々の行として記録された別の利用なので数えない（U340） |
| 範囲           | 出している月の記録の中だけで見る。書き出しの取り込みのときの突き合わせ（U335）とは別                                                                                                             |
| 計算の場所     | 画面が、受け取った記録（出所の種類・向き・日付・金額）から domain の `householdDuplicateGroups` で計算する。契約・API は変えない（記録の ID も使わない）                                         |
| 見せ方         | 記録の一覧の上に「同じ日・同じ金額の記録が別の出所からも入っています。…重なっていれば片方を削除してください。」、該当する行に「重なっているかもしれません」。自動では消さない                    |

## 原本に決めがない項目

- U340: 重なっていそうな記録の見つけ方と扱い。

## 対象外

- 店名の一致での絞り込み（通知と書き出しで店名の書き方が違うため）、月をまたぐ組、自動の削除、レシートの写真・会話の一言からの補い。

## 試験（模擬だけ）

- `scripts/household-duplicates.test.mjs`: 出所の違う組・手入力の二つ・三つの組、利用通知だけ・書き出しだけの組を数えないこと、向き・金額・日付の違い、空。
- `apps/desktop/src/renderer/screens/household/HouseholdPanel.test.tsx`: 一覧の上の知らせと行の印、重なりがないときに出さないこと。

**模擬の期待値だけ**。実データ・実機は未実施で、合格扱いにしない。

## 残ること

- レシートの写真・会話の一言からの補い（段階 3 の残り）。
- U340 の本人の確認。
