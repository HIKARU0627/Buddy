# ADR 0162: 家計簿の画面（月ごとの合計・1 か月の記録・分類の変更・削除。家計簿 段階 1 の一部）

- 日付: 2026-11-26
- 状態: 家計簿の段階 1 の部分。標準の端末画面（従来の窓）に「家計簿」の欄を置き、ADR 0161 の API まで通した。取り込みを止める手段（U326）と、外部の家計簿サービスの CSV の取り込みは後の ADR で足す。**模擬・同じプロセスの統合試験だけ**で、Electron の画面の実機確認・実データは未実施。
- 根拠: 本人の依頼（外部の家計簿サービスを Buddy の内部機能で置き換える）、ADR 0014・0132・0154・0158・0161。原本の参照手順は `docs/design/README.md`。
- 対象: `packages/contracts`（IPC の 3 チャネル、`DesktopHouseholdView`・`DesktopHouseholdEntry`）、`packages/domain/src/desktop.ts`（チャネル・受付・役割）、`apps/desktop`（`main/household-bridge.ts`・`core-link.ts`・`electron/main.ts`・`preload.cts`、`renderer/state/household-state.ts`・`use-household-state.ts`・`screens/household/HouseholdPanel.tsx`・`App.tsx`）。

## 決めたこと

| 対象           | 決定                                                                                                                                                                                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 端末の経路     | IPC は `desktop.household_view`（ロック解除済み。前面は求めない）、`desktop.household_category` と `desktop.household_delete`（ロック解除済みの画面操作）。3 つとも従来の窓と状態の層の役割表に入れ、キャンバス・入力バーには渡さない（ADR 0132・0154 と同じ）                     |
| 参照だけを渡す | 画面へは main（`HouseholdBridge`）が作る参照（ref）と表示用の値だけを渡す。記録の ID・内容版は main が持ち、送るときに `expected_content_revision` として付ける。世代（ロック・切断）が進んだら値と参照を捨てる                                                                    |
| 今月           | 画面が月を指定しないときは、中枢の月ごとの合計が返した今月（本人のタイムゾーン。U331）を読む。端末の時計で今月を決めない                                                                                                                                                           |
| 読み取り       | 月ごとの合計と 1 か月の記録を続けて読み、両方読めたときだけ反映する。重なったときは後から始めた読み取りだけを反映し、追い越された要求には `list_superseded` を返す（古い月で表示を戻さない）。読めなければ前の値のまま取得の状態を stale（読めたことがなければ unavailable）にする |
| 分類の変更     | 記録の向きと同じ分類だけを選択肢に出し、選んだらすぐ送る（何度でも直せるので問わない。U333）。今と同じ分類は送らない。受け付けたら読み直す                                                                                                                                         |
| 削除           | 画面の中で一度問う（「この記録を削除しますか。削除した記録は集計から外れ、同じ通知からは作り直しません。」）。U333                                                                                                                                                                 |
| 拒否と結果不明 | 中枢の 409 は `preview_stale`、422 などは `core_rejected` にして読み直す。届いたか分からない・5xx・形の違う 2xx は自動では送り直さず、その記録を次の読み取りまで操作させない                                                                                                       |
| 見せ方         | 選んだ月の支出・収入・収支・振替・件数と分類ごとの支出、記録の行（日付・時刻・店名・金額・支払い手段・出所）、月ごとの合計（押すとその月を出す）。金額は端末の言語の設定によらず 3 桁ごとのコンマで書く。読めない記録の数と、件数の上限で切ったことは欄の中で知らせる              |

## 原本に決めがない項目

- U333: 家計の記録の削除と分類の変更の前の確認。

## 対象外

- 取り込みを止める手段（U326）、外部の家計簿サービスの CSV の取り込み、手入力の記録。
- 状態の層（キャンバスのモード）の家計簿の画面。

## 試験（模擬・同じプロセスの統合だけ）

- `packages/contracts/fixtures/desktop-ipc-cases.json`（受付 10 件）。
- `scripts/desktop-ipc.test.mjs`・`scripts/canvas.test.mjs`・`apps/desktop/src/main/preload.test.ts`・`window-roles.test.ts`: チャネルの一覧・役割と、画面へ渡す形に記録の ID・内容版・出所の識別子が無いこと。
- `apps/desktop/src/main/household-bridge.test.ts`（7 件、模擬の接続）: 画面の値の形と ID を渡さないこと、今月の読み取り、読めなかったときの stale、変更・削除の本文と読み直し、409・422・結果不明の扱い、追い越された読み取りと世代の破棄。
- `apps/desktop/src/main/household-link.test.ts`（2 件、127.0.0.1 の Core と `DesktopCoreLink`）: 今月と 12 か月の合計、別の月の読み取り、受付の拒否が中枢へ何も送らないこと。
- `apps/desktop/src/renderer/state/household-state.test.ts`（8 件）と `screens/household/HouseholdPanel.test.tsx`（5 件、サーバー描画）。

期待値は手で書いた。Electron の画面の見た目・クリック、実データ・実機は未実施で、合格扱いにしない。

## 残ること

- 取り込みを止める手段（U326）と、外部の家計簿サービスの CSV の取り込み。
- U331〜U333 の本人の確認。
