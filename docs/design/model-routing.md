# AI の役割分担と採用条件

2026-10-18 のモデル再選定を反映した評価計画。下表は採用候補であり、稼働中の構成や精度評価の結果ではありません。

| 役割                               | 第一候補          | 境界                                                        |
| ---------------------------------- | ----------------- | ----------------------------------------------------------- |
| 音声会話・読み上げ                 | GPT-Live-1        | 処理は Core へ委譲。文字応答だけの依頼では呼ばない          |
| 即時の意図と引数・短い文字応答     | GPT-6 Luna        | 原則1回で解釈。形式と意味を Core が検証                     |
| メール抽出・返信案・要約・記憶候補 | Claude Haiku 5.5  | 根拠と入力版を保持。結果を直接操作や保存の権限にしない      |
| 明示された高度相談                 | Claude Sonnet 5.5 | 追加の優先比較候補。実測前の自動昇格なし                    |
| 端末内の音声認識                   | ReazonSpeech      | 音声→文字応答と音声入力の区間確認。実機精度・遅延を別途検証 |

通常の調査要約は Haiku / Luna、深い相談は Sonnet を比較します。Gemini 3.8 Flash は比較基準、DeepSeek と小型ローカルモデルは主要候補の不足が残る場合の第二段階。Decisions API は分類の影モード候補で、任意引数生成や実行承認の代わりにはしません。

`packages/contracts/model-evaluation.json` はこの候補一覧の機械可読版です。価格・endpoint の能力・SDK 版・実測結果を登録していないため、実行可能な deployment manifest として読み込んではいけません。採用時は別の manifest で価格版、schema / prompt hash、上限、同時数、固定版または可変名、戻し先、用途別評価を記録します。

## 付帯 API クレジット

適用可能なクレジットは、通常料金による利用額と、適用後の追加支出を分けて扱います。付帯額・契約料・個人の予算をこのリポジトリへ固定しません。Claude 向けクレジットを他社の音声・LLM・検索へ相殺しません。
請求周期、失効、共有組織の消費、残高の取得時点を確認します。残高不明や枯渇を理由に、購入残高・後払い・他モデルへ自動移行しません。通常料金による予約 R と最大負担 M、評価 campaign の停止条件も維持します。

## 次の評価

1. 本人確認済みの合成・許可された正解例を固定する。
2. 即時解釈と文章生成を別セットで比較し、正確さ、保留、完成結果までの時間、usage を記録する。
3. 合格した用途だけ manifest を有効化する。意図の評価だけで返信・記憶へ採用しない。
4. ローカルと音声は実機で検証する。公開の速度値を Buddy の測定値として扱わない。

外部 API の課金やアカウント設定は今回変更していません。
