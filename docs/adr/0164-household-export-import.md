# ADR 0164: 外部の家計簿サービスの書き出しの取り込み（家計簿 段階 1 の一部）

- 日付: 2026-11-26
- 状態: 家計簿の段階 1 の部分。外部の家計簿サービス（マネーフォワード ME）の入出金履歴の書き出し（CSV）を一度だけ取り込み、Buddy の家計簿へ移る。取り込みの開始より前の利用（U327）と、取り込みを止めていた間の利用（U334）もこれで補う。**模擬の試験だけ**で、実在の書き出しでの確かめは未実施（日付・金額の書き方と文字コードは U336）。
- 根拠: 本人の依頼（外部の家計簿サービスを Buddy の内部機能で置き換える。段階 1 に CSV の一度の取り込みを含める）、ADR 0158・0160・0161・0162。列の名前は同サービスの公式のヘルプ（入出金履歴のダウンロードの項目）で確かめた。
- 対象: `packages/domain/src/household-import.ts`、`packages/contracts`（`HouseholdImportRow`・`HouseholdImportRequest`・`HouseholdImportResult`・`POST /v1/household/imports`、IPC の `desktop.household_import`、`DesktopHouseholdView.last_import`）、`apps/core/src/api-household.ts`、`apps/desktop`（`HouseholdBridge.importExport`・`electron/main.ts` のファイル選択・画面の取り込みの欄）。

## 決めたこと

| 対象             | 決定                                                                                                                                                                                                                                                |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ファイルの選び方 | 端末の main が OS のファイル選択を出して本人に選ばせる（16 MB まで）。画面はパスも中身も渡さない（画面から任意のファイルを読ませない）                                                                                                              |
| 文字コード       | UTF-8（BOM の有無を問わない）として正しければ UTF-8、そうでなければ Shift_JIS として読む（U336）                                                                                                                                                    |
| 列               | 見出しの名前で探す（並びに頼らない）。金額の列の括弧は全角・半角のどちらも受ける。日付は YYYY/MM/DD と YYYY-MM-DD、金額は桁区切りのコンマと先頭の符号（U336）                                                                                       |
| 行の写し方       | 振替が 1 なら振替、金額が負なら支出、正なら収入。支出の分類は大項目の名前（分類の表示名と同じ）で引き、引けなければ未分類。店名は「内容」、支払い手段は「保有金融機関」。家計の記録の検査に合わない項目（長い数字の並びなど）は空にして行は取り込む |
| 取り込まない行   | 計算対象が 0（本人が集計から外した行）・金額 0・日付や金額や ID が読めない行。数だけ画面に出す                                                                                                                                                      |
| 二重の記録       | 出所の鍵は ID の列（ADR 0158）で、取り込み直しても増えない。同じ日・同じ金額の利用通知の記録がある支出の行は、同じ利用として取り込まない（一つの通知に一つの行。U335）                                                                              |
| 送り方           | main が日付の順に組（100 行まで、同じ日の行は同じ組）に分けて一つずつ送る。中枢は家計の記録の検査をし直す。途中で送れなくなったら送り直さずに止め、画面に「止めた」と出す（取り込み直せば記録済みの行は増えない）                                   |
| 分類の規則       | 支出の分類が決まっている行は、店名の分類の規則（取り込みの規則）として覚える。本人の規則は上書きしない（ADR 0158）。未分類の行には既にある規則を当てる                                                                                              |
| 検査             | 本人の画面操作だけ（ロック解除済み・前面）。中枢の経路も接続範囲と画面操作を求める                                                                                                                                                                  |

## 原本に決めがない項目

- U335: 書き出しの取り込みと利用通知の記録の重なり。
- U336: 書き出しの日付・金額の書き方と文字コード。

## 対象外

- 手入力の記録、記録の金額・日付・店名の変更。
- マネーフォワード ME 以外の書き出し。

## 試験（模擬だけ）

- `scripts/household-import.test.mjs`（5 件）: CSV の欄の分け方（引用符・改行・BOM・壊れた引用符）、支出・収入・振替の写し方、取り込まない行の数え方と口座番号らしい店名を空にすること、見出しを名前で探すこと・足りない見出し・同じ ID、利用通知と突き合わせる鍵。書き出しの中身はすべて合成。
- `apps/core/src/api-household.test.ts`: 行の記録・取り込み直しで増えないこと・同じ日と金額の利用通知と一つだけ突き合わせること・検査に合わない行・規則を覚えて次の未分類に当てること・書き出しの元の誤り・データ鍵がないこと・101 行の拒否。
- `apps/desktop/src/main/household-bridge.test.ts`: 文字コードの判定（UTF-8・Shift_JIS・どちらでもない）、組の分け方、送る本文と合計、ファイルを選ばなかったとき・読めないファイル・途中で送れなくなったときに送り直さないこと、世代の破棄。
- 画面の状態と欄の試験、`desktop-ipc-cases.json` の受付 3 件。

**模擬の期待値だけ**。実在の書き出し・実機は未実施で、合格扱いにしない。

## 残ること

- 実在の書き出しで日付・金額の書き方と文字コードを確かめる（U336）。
- U335 の本人の確認。段階 2（固定費・予算）と段階 3（レシート・会話・突き合わせ）。
