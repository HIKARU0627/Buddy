# ADR 0161: 家計簿の API（月ごとの合計・1 か月の記録・分類の変更・削除。家計簿 段階 1 の一部）

- 日付: 2026-11-26
- 状態: 家計簿の段階 1 の部分。ADR 0158 の記録を端末から読み、本人が分類を直し、記録を消すための HTTP の経路を作る。端末の画面（IPC・main・renderer）と、取り込みを止める手段（U326）はこの後の ADR で足す。**模擬の試験だけ**で、実データ・実機は未実施。
- 根拠: 本人の依頼（外部の家計簿サービスを Buddy の内部機能で置き換える）、ADR 0131・0143・0158・0160。原本の参照手順は `docs/design/README.md`。
- 対象: `packages/contracts`（OpenAPI の 4 経路、JSON Schema の家計簿の定義、`api-cases.json`・`schema-cases.json`）、`scripts/contract-tools.mjs`（意味検査）、`packages/domain/src/api.ts`（経路の検査）・`household.ts`（`householdMonthShift`）、`apps/core/src/api-routes.ts`（パスの値の Schema）・`api-household.ts`・`core.ts`。

## 背景

ADR 0158 で記録の保存・暗号化・月の集計・分類の変更・削除を Core の関数として作り、ADR 0160 で利用通知メールからの自動の取り込みを足した。記録は増えるが、端末から見る・直す経路が無かった。家計の記録は Buddy 自身の記録で外部を変えないため、操作・承認・自動実行の経路は通さず、専用の経路にする（ADR 0158）。

## 決めたこと

| 対象               | 決定                                                                                                                                                                                                                                                                                |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 経路               | `GET /v1/household/months`（月ごとの合計）、`GET /v1/household/months/{month}`（1 か月の記録と集計）、`POST /v1/household/entries/{entry_id}/category`（分類の変更）、`POST /v1/household/entries/{entry_id}/delete`（削除）                                                        |
| 検査               | 読み取りは端末トークン・自宅・ロック解除（金額・店名を含む）。変更と削除は加えて接続範囲と本人の画面操作。チャット窓口（ADR 0143）からは受けない（U332）                                                                                                                            |
| 今月と範囲         | 今月は Core が本人のタイムゾーン（ADR 0131）で決め、今月から 11 か月前までの 12 か月の合計を新しい月から返す。記録のない月も 0 で入れる。タイムゾーンが決まらない・12 か月の範囲が 2000〜2099 年に収まらない（中枢の時計の狂い）ときは 503 で、端末の時計・UTC で代用しない（U331） |
| 月の指定           | 1 か月の経路の月はパスの値（`YearMonth`）。経路の表にパスの値の Schema を指定できるようにした（今までは `Id` だけ）。家計の記録の範囲（2000〜2099 年）の外は 422。クエリーは秘密を URL に置かない方針の検査（`cursor` だけ）を変えないために使わない                                |
| 返す中身           | 記録は向き・金額・日付・時刻・分類・店名・メモ・支払い手段・内容版・出所の種類・作成と更新の時刻。出所の識別子（メールの ID・アカウント・書き出しの行）は返さない。復号できない記録は数（`unreadable`）だけ、件数の上限で切ったときは `truncated`                                   |
| 照合               | 変更と削除は本文の `expected_content_revision` を経路の処理で照合する（保存層でも同じ値で照合し直す）。内容版の違い・削除済みは 409、向きの違う分類・ない記録は 422。内容版の型（`HouseholdRevision`）は ADR 0003 の共通の 10 進の形で、保存しない値の 0 は 422                     |
| 同じ要求の再送     | 変更は内容版を、削除は状態を進めるので、同じ `request_id` の再送は 409 になり二重に効かない（安全停止の解除と同じ扱い。ADR 0152）。画面は読み直して確かめる                                                                                                                         |
| 失敗               | データ鍵が読めない・保存の失敗・成否不明は 503 `dependency_unavailable` にし、成功にも競合にも見せない                                                                                                                                                                              |
| 応答の意味検査     | 分類の向きと記録の向き、暦に実在する日付、月と記録の日付、記録の並び、集計と記録の合計、差額、分類ごとの合計の和と並び、12 か月の連続を、契約の検証ツールが確かめる。分類と向きの表は domain と同じであることを試験で照合する                                                       |
| 分類の変更の副作用 | 店名がある記録は、本人の規則として店名の HMAC に分類を覚える（ADR 0158）。応答の `rule_learned` で覚えたかを返す                                                                                                                                                                    |

## 原本に決めがない項目

- U331: 家計簿の画面の「今月」と月ごとの合計の範囲。
- U332: 分類の変更・削除を受ける入口。

## 対象外

- 端末の画面（IPC のチャネル・main の橋渡し・renderer の欄）。
- 取り込みを止める手段（U326）、外部の家計簿サービスの CSV の取り込み、手入力の記録。
- 記録の金額・日付・店名の変更（今は分類の変更と削除だけ）。

## 試験（模擬だけ）

- `packages/contracts/fixtures/api-cases.json`（4 経路の要求・応答・拒否・不正な本文）と `schema-cases.json`（家計簿の定義の正しい例・形の誤り・意味検査の拒否）。
- `scripts/household.test.mjs`: 月をずらす関数（年またぎ・2000〜2099 年の外）、契約の分類の一覧と向きの表が domain と同じこと。
- `apps/core/src/api-household.test.ts`（7 件）: 一時の DB で、日本時間の月の境目（UTC ではまだ前の月）の今月、12 か月の合計（振替を支出・収入に入れない・範囲の外を数えない）、タイムゾーン・データ鍵・時計の狂いの 503、1 か月の並び・出所の識別子を返さないこと・復号できない記録の数、範囲の外の月の 422、分類の変更と規則・再送と古い版の 409・向きの違い・ない記録の 422、削除と再送・削除済みの 409、書込みの成否不明・失敗と読み取りの失敗の 503。
- `apps/core/src/api-routes.test.ts`: 経路の数（55）とロック状態の申告の数（44）。

**模擬の期待値だけ**。実データ・実機・端末の画面は未実施で、合格扱いにしない。

## 残ること

- 家計簿の画面（月の一覧と合計、分類の変更、削除）と、取り込みを止める手段（U326）。
- 外部の家計簿サービスの CSV を一度だけ取り込む機能。
- U331・U332 の本人の確認。
