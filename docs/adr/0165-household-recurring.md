# ADR 0165: 定期の支出と固定費の目安（家計簿 段階 2 の一部）

- 日付: 2026-11-26
- 状態: 家計簿の段階 2 の部分。毎月決まって払っている支出（サブスクリプション・公共料金・保険・家賃など）を記録から見つけ、月の固定費の目安を出す。予算と請求予定は後の ADR で足す。**模擬の試験だけ**で、実データでの確かめは未実施。
- 根拠: 本人の決定（段階 2: 定期の支出を見つけて固定費と予算を出す）、ADR 0158・0161・0162。
- 対象: `packages/domain/src/household-recurring.ts`、`packages/contracts`（`HouseholdRecurringItem`・`HouseholdRecurringSummary`、`HouseholdOverview.recurring`、`DesktopHouseholdView.recurring`）、`scripts/contract-tools.mjs`（意味検査）、`apps/core/src/api-household.ts`、`apps/desktop`（橋渡しと画面の「定期の支出（固定費の目安）」）。

## 決めたこと

| 対象             | 決定                                                                                                                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 保存             | 保存しない。月ごとの合計（`GET /v1/household/months`）が読む直近 12 か月の記録から、中枢が毎回計算して `recurring` で返す。本人が分類や記録を直せば次の計算に反映される                          |
| 同じ店           | 店名を正規化して比べる（ADR 0158 と同じ。英字の大文字・小文字、全角・半角をそろえる）。店名のない記録・支出でない記録は数えない                                                                  |
| 定期とみなす条件 | 12 か月のうち 3 か月以上に現れ、最後に現れたのが今月か先月（やめたサブスクリプションを数え続けない）、1 か月の回数が平均 2 回以下（毎日の買い物を外す）、月の合計の最大が最小の 2 倍以内（U337） |
| 金額の目安       | 現れた月ごとの合計の中央値（偶数個なら小さい方）。固定費の目安はその合計                                                                                                                         |
| 表示             | 家計簿の欄に「定期の支出（固定費の目安）」として、月の固定費の目安と、店名・分類・目安・現れた月の数を目安の大きい順に出す。見つからなければそう書く。読めていなければ出さない                   |
| 意味検査         | 固定費の目安が目安の合計であること、目安の大きい順であることを契約の検証ツールが確かめる                                                                                                         |

## 原本に決めがない項目

- U337: 定期の支出とみなす条件。

## 対象外

- 年払い・隔月払いの支出、本人が定期の支出を登録・除外する手段、予算、請求予定。

## 試験（模擬だけ）

- `scripts/household-recurring.test.mjs`（2 件）: 条件ごとの採否（2 か月だけ・やめた店・毎日の買い物・金額の幅・収入・店名なし）、店名の正規化、同じ月の 2 回の合計、年をまたいだ先月、記録なし。
- `apps/core/src/api-household.test.ts`: 月ごとの合計の `recurring`。
- `apps/desktop`: 橋渡しの値と、欄の表示（目安・店名と分類・月の数・見つからないとき・読めていないとき）。

**模擬の期待値だけ**。実データは未実施で、合格扱いにしない。

## 残ること

- 分類ごとの予算（段階 2 の残り）と、請求のメールを「請求予定」として支払い済みと分けること。
- U337 の本人の確認。
