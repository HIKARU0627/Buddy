# ADR 0174: 会話の一言からの収入の記録の候補（家計簿 段階 3 の一部）

- 日付: 2026-11-26
- 状態: 家計簿の段階 3 の部分。ADR 0171 の会話の一言からの候補を、支出だけでなく収入にも広げた。「給料が 25 万円入った」「お小遣いを 5000 円もらった」「フリマで 3,000 円売れた」のような一言を決まった規則で読み、家計簿の欄の手入力の入力欄（ADR 0167）に、向き「収入」・分類「収入」で値を入れて開くところまでを作った。記録を作るのは、本人が入力欄で中身を確かめて「足す」を押したときだけ。**模擬の試験だけ**で、実データ・実機は未実施。
- 根拠: 本人の決定（段階 3: 会話の一言からの補いで本人の手間を減らす。収入の候補は段階 3 の残り）、ADR 0161・0167・0171・0173。原本（非公開 Notion）に家計簿の決めはない（U318 以降と同じ）。
- 追補: 2026-11-26 の見直しで確かめられた読み違い（お金を出した話・振替・単価を収入にする、お釣りなどの言葉で収入の話を見落とす）を直した。末尾の「追補」を参照。
- 対象: `packages/domain/src/household-utterance.ts`（一言の読み方）、`apps/desktop` の renderer（`state/household-candidate.ts`・`household-state.ts`・`work-state.ts` の注記、`screens/work/WorkPanel.tsx`・`screens/household/HouseholdPanel.tsx`）。契約（JSON Schema・OpenAPI・IPC）、Core、保存層、マイグレーションは変えない。

## 背景

ADR 0171 では、一言から読むのを支出だけにした（U345 の暫定 (a)）。収入（給料・お小遣い・フリマの売り上げ）は、家計簿の欄の「記録を手で足す」で向きを「収入」に変え、金額・日付を一つずつ入れる必要があり、支出と同じ手間がかかる。収入はメールの利用通知で入らないので、手で入れる場面が支出より多い。

一方で、収入の言い方は支出より紛らわしい。「500 円戻ってきた」は返金か収入か決められず、「おごってもらった」「お釣りをもらった」「貸したお金を返してもらった」は本人のお金が増えた話ではない。「口座に移した」は振替で、収入ではない。支出と収入を取り違えた候補は、本人が確かめずに「足す」を押すと月の合計を二重に狂わせる（支出が減り、収入が増える）。そこで、ADR 0171 の境界（LLM を使わない・候補は記録ではない・手入力の経路だけで記録する・候補は renderer のメモリーだけ）を変えずに、読む言い方を狭く決め、紛らわしいものは候補にしないことにした。

### 支出の読み方で変わったこと

収入の話と取り違えないため、支出の一言の読み方も次の点で変わった。どちらも候補を出さない側への変更で、取り違えた候補を出すことはない。

- 支出の言い方があっても、収入の話（もらって・売って・稼いで・振り込まれ・「円入って」「が入って」など）が一言の中にあれば `direction_unclear` にする（「お小遣いをもらったので 500 円使った」）。ただし、お釣り・立て替えなど収入にしない言葉があるときは収入の話に数えず、今までどおり支出の候補にする（「コンビニで 800 円払った。お釣りももらった」）。「店で売ってた」「売れ残り」「売り場」「店に入って」は収入の話に数えない（U354）。
- 「戻ってきた」「戻った」のある一言は、支出の言い方があっても `direction_unclear` にする（「払った 500 円が戻ってきた」は返金の話のことが多い）。「家に戻った後、500 円使った」も候補にならない（U354）。
- 負の金額の理由の文から「収入は家計簿の欄から足してください」の旨を除いた（収入も候補にできるようになったため）。

## 退けた案

| 案                                                                            | 退けた理由                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 出どころを店名・相手の欄に入れる                                              | 中枢は、手入力の記録の店名があり分類が未分類でなければ、店名の規則として覚える（ADR 0167）。収入の分類は「収入」なので、「メルカリで 3000 円売れた」を足すと「メルカリ → 収入」の規則を覚え、本人が付けた「メルカリ → 趣味・娯楽」（支出）の規則を上書きする。収入の規則は支出の記録には当たらない（`householdRuleApplies`）ので、支出の規則が黙って消える（U353）。この弊害は、ADR 0175 で中枢が収入・振替の記録から規則を覚えないように直したので、今はない |
| 金額のすぐ後の言い方で向きを決める（「3000 円で売った後、本を買った」は収入） | 日本語の文の組み立てで金額がどの言い方にかかるかを決まった規則で決めるのは難しく、取り違えた候補を出すおそれがある。取り違えは本人が見落とすと合計を二重に狂わせるので、両方ある一言は候補にしない                                                                                                                                                                                                                                                            |
| 「戻ってきた」を収入として読む・支出の取り消しとして読む                      | 返金・払い戻し（元の支出を直す話）と、貸したお金の返済・保証金の返還（収入でも支出でもない）と、収入が混ざる。どれかに決めると取り違えが出る                                                                                                                                                                                                                                                                                                                  |
| 「受け取った」「当たった」「出た」も収入として読む                            | 「代引きで 3000 円の荷物を受け取った」（支払い）、「500 円のお菓子が当たった」（品物）、「500 円の赤字が出た」のように収入でない場面が多い。実際の使い方で足りなければ U352 で広げる                                                                                                                                                                                                                                                                          |
| 収入の候補を LLM で読む                                                       | ADR 0171 の退けた理由（契約・意図表・評価まで変える。LLM の出す金額・日付は信用できず、結局は本人の確かめが要る）と同じ                                                                                                                                                                                                                                                                                                                                       |

## 原本に決めがない項目

- U345: 会話の一言から読む範囲（支出と収入に広げた。この ADR で更新）。
- U352: 会話の一言から読む収入の言い方と、収入にしない言い方。
- U353: 収入の候補の出どころを入れる欄（メモにするか、店名・相手にするか）と、手入力の収入の記録が店名の規則を上書きすること。
- U354: 支出と収入の言い方が両方ある一言と、「戻ってきた」の扱い（支出の一言の読み方も変わる）。

## 対象外

- 振替の候補、分類（支出の分類）・時刻の読み取り、複数の記録をまとめた一言。
- 品物の値段の言い方（「1000 円のお菓子をいただいた」）。追補で、金額が名詞にかかる形は読まないことにした（それまでは 1000 円の収入の候補になった）。
- 中枢が手入力の収入・振替の記録から店名の規則を覚えること。この ADR では変えず、ADR 0175 で、規則を覚えるのを支出の記録だけにした（U355）。
- キャンバスの入力バー・音声からの候補（U346・U350・U351、ADR 0173）。

## 残ること

- 画面の見た目と操作は Electron の実機で未確認。手順は `docs/household/README.md` の項目 I（I8〜I13）。U355 の手順は項目 G（G5・G6）。
- U352〜U354 の本人の確認。とくに、出どころをメモに入れること（U353）と、支出と収入の話が両方ある一言を候補にしないことで、支出の一言の一部（「お小遣いをもらったので 500 円使った」「家に戻った後、500 円使った」）も候補にならなくなったこと（U354）。
- U353 の (b)（出どころを店名・相手に入れる）にするかは、画面の見え方で本人が決め直す。前提だった中枢の規則の覚え方は ADR 0175 で直した（収入・振替の記録から店名の規則を覚えない。U355）ので、(b) にしても同じ店名の支出の規則は上書きされない。

## 追補（2026-11-26）: 節の扱い・お金を出す言い方・振替・単価の見直し

見直しで確かめられた誤りの修正。どれも候補を出さない側（取りこぼしの側）への変更で、U354 の「支出と収入を取り違えるより、取りこぼす側に倒す」に沿う。**模擬の試験だけ**で、実データ・実機は未実施。

直す前の誤り（今日を 2030-11-26 として `readHouseholdUtterance` を呼んで確かめた）:

- お金を出した話を収入にした。収入の言い方が文の終わりにあるかだけを見て、金額と同じ節にあるかを見ていなかった。「家賃 8 万円振り込んだら、確認の連絡をもらった」「500 円出したら、おまけをもらった」「1000 円寄付したら、お礼状をいただいた」「3000 円のチケットを予約したら、確認のメールが入った」「電気代の請求が 8000 円入った」「欲しかった本が 2000 円で手に入った」などが収入の候補になった。
- お釣り・立て替え・ポイント・割り勘の言葉が一言のどこかにあると、支出の言い方がある一言で収入の話を調べなかった。「給料が 25 万円入った。立て替えてた分を払った」が 250,000 円の支出、「フリマで 3000 円売れた。お釣りで飴を買った」が店名「フリマ」の 3,000 円の支出になった。
- 振替・両替・値引きを収入にした（「Suica に 3000 円入った」「ATM から 3 万円入った」「1 万円を両替でもらった」「500 円の割引をもらった」）。
- 単価を金額にした（「時給 1000 円で 8 時間稼いだ」が 1,000 円の収入）。
- 「500 円分包んでもらった」が収入になった（「〜てもらった」は除いていたが、「〜んでもらった」は除いていなかった）。
- 「明日給料が 25 万円入った」の日付が今日、メモが「明日給料」になった。「8 時間で 1 万円稼いだ」のメモが「8 時間」、「入った店で 500 円使った」の店名が「入った店」になった。

| 対象                       | 決定                                                                                                                                                                                                                                                                                                                        |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 節                         | 一言を、読点・句点・「!」「?」・数の中でないコンマと点と、「たら」「ので」「のに」「けど」「けれど」「たから」「だから」「ながら」の後ろで節に分ける                                                                                                                                                                        |
| 収入の言い方と金額         | 収入の言い方は、金額と同じ節で金額より後にあるときだけ、その金額の話として数える。金額と別の節にあれば読まない（「1 万円貯まったので、ご褒美をもらった」）。言い方の後に読点だけを挟んで金額を言い足し、そこで一言が終わる形（「給料が入った、25 万円」）は今までどおり読む                                                 |
| 金額が名詞にかかる形       | 金額の後が「の」（「分の」「相当の」を含む）なら、後ろの収入の言い方は金額の話ではないので読まない（「3000 円のチケット」「8 万円の引き落とし」「1000 円のお菓子をいただいた」「25 万円の給料が入った」）                                                                                                                   |
| お金を出す言い方           | 振り込んだ・渡した・出した・あげた・差し上げた・おごった・寄付・募金・包んだ・返した・引き落とし・請求を、支出の話として数える（支出の候補としては今までどおり読まない）。収入の話と両方ある一言は `direction_unclear`（「500 円出したら、おまけをもらった」「電気代の請求が 8000 円入った」）                              |
| お釣りなどの言葉の範囲     | 支出の言い方がある一言では、お釣り・立て替えなどの言葉と同じ節の収入の話だけを数えない（「コンビニで 800 円払った。お釣りももらった」は支出のまま）。別の節の収入の話は数え、`direction_unclear` にする。収入の候補は、今までどおり一言のどこかにこれらの言葉があれば出さない（どの節の話か決まった規則で決めきれないため） |
| 「入った」の行き先と知らせ | 「入った」は、すぐ前が「に」（手に入った・気に入った・口座に入った）なら数えない。同じ節の頭からの部分（頭の時の言葉を除く）に「に」「から」（「口座に」「Suica に」「ATM から」「貯金から」）か、知らせの言葉（通知・連絡・メール・メッセージ・知らせ・電話・予約・予定・注文）があっても数えない                          |
| 給料などの言葉と行き先     | 「口座に給料が 25 万円入った」「給料が口座に 25 万円入った」のように給料などの言葉があっても、行き先のある「入った」は読まない（取りこぼしの側）。「給料が 25 万円入った」「25日に給料が 25 万円入った」（頭の日付は行き先に数えない）は読む。「会社から 25 万円入った」も読まなくなる                                      |
| 両替・値引き               | 両替・割引・値引き・ディスカウントを、収入として数えない言葉（お釣り・立て替えなどの一覧）に足した                                                                                                                                                                                                                          |
| 単価                       | 金額のすぐ前が、時給・日給・月給・週給・単価、「1」「一」「ひと」と助数詞（個・本・枚・つ・人・回・時間など）、あたり・当たり・につきなら、候補にせず理由を出す（`unit_price`、新しい理由）。支出も同じ（「1 個 200 円のパンを 3 個買った」）。「月給 25 万円が振り込まれた」も候補にしない                                 |
| 「〜んでもらった」         | 「〜てもらった」と同じく読まない（「500 円分包んでもらった」「母に 5000 円振り込んでもらった」）。助詞の「で」の後（「5000 円を現金でもらった」）は読む。「母から 5000 円振り込まれた」は読む（U352）                                                                                                                       |
| 日付の言葉                 | 明日・あした・明後日・あさって・ついたちを、日付を空にする言葉と、店名・出どころの前から除く時の言葉に足した                                                                                                                                                                                                                |
| 店名・メモに入れない言い方 | 数と助数詞だけの言い方（「8 時間」「3 回」「3 個」）と、「た店」「たお店」「たところ」のように店を指すだけの言い方（「入った店」）は、店名・メモに入れない                                                                                                                                                                  |
| 画面の理由の文             | `unit_price` は「時給や 1 個あたりの値段のような単価は、受け取った額や払った額と違うことがあるため、家計簿の記録の候補にしていません。合計の金額で言うか、家計簿の欄の『記録を手で足す』から入れてください。」                                                                                                              |
| 入力欄の頭の説明           | 会話の一言の候補で開いた入力欄の頭の説明は、候補の向きではなく今の入力の向きで選ぶ。収入の候補で開いた後に本人が向きを支出へ変えたら、分類を選ぶよう求める支出の説明にする。振替へ変えたら「向きは振替です」の説明にする                                                                                                    |
