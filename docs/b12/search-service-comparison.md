## 1. 先に結論

**設計の第一候補どおり Brave Search API を推奨する。ただし条件が 1 つある。**

Brave は Tavily より単価が安く（約 1.02 円/検索）、価格がリクエスト単位で固定なので B07 の R／M の門にそのまま載る。円換算では Mojeek のほうがさらに安いが、GBP 建て・カード登録必須で、日本語の質が不明という代償がある（§3.1・§3.4・§7）。一方で、**Brave の規約は検索結果の保存を許していない**（動作に必要な一時的な保存を除く）。Buddy は出典を後から確認できる形で残す設計なので、Brave を選ぶなら次のどちらかにする必要がある。

- (推奨) **検索応答を永続保存しない。** 出典は、その場で表示する URL・取得時刻・Buddy が自分で取得した本文からの抜粋・自分の要約で作り、**保存してよいかの確認が取れるまでは永続化しない**。本文の取得は B12-04 で自前に行うため、この形は設計と両立する。ただし検索応答に含まれる URL も規約上の「Search Results」に含まれると読めるため、**URL の保存可否も B12-02 で確認する**（§3.2）。
- 検索結果そのものを残したい場合は、保存権を明示している **Mojeek の Business プラン**が対抗候補になる（§7 の選択肢 B）。

Tavily は API と料金の面では使いやすいが、**入力と出力を AI の学習に使いうる条項**があり、個人アシスタントの既定にはしない（§3.6）。

- 設計は「無料クレジットを予算計算に入れず、安全側に見積もる」としている。上の「月 300 円で賄える検索」も無料枠を数えていない。無料枠を数えるなら Brave（約 1,000 回分）と Tavily（1,000 回分）は月 300 円分を超えるが、**無料枠は予告なく変わりうる**ので、B07 の門では数えない扱いを維持するのが安全。Mojeek の無料クレジットの量は公開ページからは不明。
- Mojeek は GBP 建てで、設計の試算（USD）と通貨が違う。円換算には為替の仮定が要るため、上の円は**比較のための概算**であり、B07 の price_version に入れる値ではない。
- Tavily の `auto_parameters` を有効にすると、リクエストが自動で advanced（2 クレジット）に上がることがある。M を固定するため、**明示的に basic を指定し、auto_parameters を使わない**。
- Tavily の Research は 1 リクエストのクレジットが `model=pro` で 15〜250、`model=mini` で 4〜110 の幅を持つ。B12 では使わない（M を固定できない）。

**Buddy への影響（重要）**

- 設計は「検索結果と根拠の短い抜粋・取得時刻・URL を対応させる」としている。Brave を選ぶ場合、**Brave が返したタイトル・スニペットをそのまま保存することはできない**。
- Brave の規約は「Search Results」を API からの全出力と定義している（1.10）。検索応答に含まれる **URL もこの定義に含まれる**と読めるため、URL だけを残すことが許されるかは**未確認**。B12-02 で Brave に確認するか、法務確認が済むまで永続保存しない。
- 保存を減らす候補は「保存するのは取得時刻・**B12-04 で自分が取得した本文からの抜粋**・自分の要約だけにし、Brave の URL・`description`／`extra_snippets` はその場の表示にだけ使う」形。ただし URL も保存できないとなると出典の再表示が難しくなるため、**この形を採るかは URL の保存可否の確認後にする**。本文を取得できなかったページ（会員限定・PDF・失敗）は、その場では URL と「本文未取得」を表示する（B12-04 の区別をそのまま使う）。
- Mojeek の Business の保存権は**料金ページの FAQ の説明**で、規約本文には Startup の制限と Enterprise の別条件だけが書かれている。契約時に「Business で無期限の保存ができる」ことを書面で確認する。
- Tavily は保存を禁じていないが、§3.6 の学習利用と表裏なので、保存の可否だけでは選ばない。

## 4. B07 の予算の門（R／M）との整合

B07（#12）で、有料の要求は受付の transaction で **予約額 R** と **最大負担 M** の両方を検査する。M を有限に制限・検証できないものは p95 予約を使えない。検索の枠は月 300 円で、LLM（1,700 円）・音声（4,000 円）と融通しない（設計05、ADR 0006・0042、`docs/b07/README.md`、`packages/contracts/schemas/buddy.schema.json` の `BudgetServiceRoutes.search`）。

| 観点               | Brave                                                         | Tavily                                                                                                 | Mojeek                                           |
| ------------------ | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| 1 回の費用が固定か | **固定**（$0.005/リクエスト。結果数・本文の有無で変わらない） | **固定**（basic 1・advanced 2 クレジット）。`auto_parameters` を使わなければ固定                       | **固定**（プランの 1,000 リクエスト単価）        |
| R と M             | R = M = 単価 × 回数。p95 は不要                               | 同じ。basic を明示する                                                                                 | 同じ。プランと通貨（GBP）を price_version に持つ |
| 3 検索/依頼の M    | 約 3.06 円                                                    | basic 約 4.90 円／advanced 約 9.79 円                                                                  | Business 約 2.16 円（£1 = 200 円の仮）           |
| 応答喪失時         | B07 のとおり R・M を保持し、0 円にしない                      | 同じ（`request_id` は応答に含まれるため、喪失時の照合は usage／logs の口で可能かを B12-02 で確認する） | 同じ                                             |
| 価格の版           | USD。為替は設計の試算値を使う                                 | USD。プランにより単価が変わるので版を分ける                                                            | **GBP**。為替の扱いを B12-02 で決める            |
| 無料枠             | 予算計算に入れない（設計の扱い）                              | 同じ                                                                                                   | 同じ                                             |

- **検索は LLM と違い、1 回の費用が完全に固定**なので、B07 の M の検査と相性がよい。p95 の実測を待たずに B12-03 を始められる。
- 注意すべきは Tavily の `auto_parameters`（advanced へ自動で上がる）と Research（15〜250 クレジットの幅）だけ。どちらも使わなければ M は固定できる。
- Mojeek は通貨が GBP のため、B07 の price_version に currency を持たせ、為替の仮定を明示する必要がある。設計の試算（170 円/米ドル）をそのまま GBP に当てない。
- 予算の門は「検索の枠 300 円」で見る。LLM の 1,700 円や音声の 4,000 円から補填しない（B07 の既存の規則）。

## 5. 上限の案

設計の初期値（1 依頼 3 検索・本文 5 ページ・1 ページ 2MB／15 秒・リダイレクト 3 回）を維持する。そのうえで、**月 300 円の枠と両立する日次の目安**を足す。

| 項目           | 案                                                                               | 根拠・計算                                                                             |
| -------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 1 依頼の検索   | **3 回**（設計の初期値を維持）                                                   | 1 依頼 = 1 回の調査。3 回で足りない場合は追加せず、結果に「検索 3 回で打ち切り」を示す |
| 1 依頼の本文   | **5 ページ**、1 ページ 2MB・15 秒、リダイレクト 3 回（設計の初期値を維持）       | 処理と費用の上限。品質の保証ではない                                                   |
| 1 日の検索     | **9 回（= 3 依頼）を目安**                                                       | Brave で 9 × 1.02 × 30 日 = 約 275 円。月 300 円に収まる                               |
| 月の検索       | **300 円を上限（hard）**                                                         | B07 の検索の枠。超える予約は拒否                                                       |
| 予算不足のとき | **保留**（完了と表示しない）。検索回数を減らせる場合は減らし、その旨を結果に残す | Issue #27 の完了条件「失敗を完了と表示しない」                                         |
| 個別承認       | 本人が画面で承認した依頼だけ、超過枠 500 円の範囲で実行                          | B07 の既存の規則。自発の処理には使わない                                               |

**設計の例と枠の食い違い（B12-02 で直す）**

- 設計05 の費用の表には「標準試算: 検索 300 回/月」の例がある。Brave の単価で 300 回は **約 306 円**となり、検索の枠 300 円をわずかに超える。
- これは「標準試算」が LLM と検索を合わせた利用の目安であり、**検索の枠の上限値ではない**と読むべき。B12-02 で、上限の説明と試算の例を混同しないように書き分ける。
- 月 300 円で賄えるのは Brave で約 294 回（3 検索/依頼で約 98 依頼）。日 9 回の目安は、この範囲に収まるように置いた。

## 7. 選択肢と影響（本人が選ぶ）

### A. Brave Search（推奨・条件付き）

- 料金: 約 1.02 円/検索。月 300 円で約 294 検索（約 98 依頼）。毎月 $5 の無料クレジットがあるが、予算には数えない。
- 保存: **検索応答（URL を含む）の永続保存は未確認**。確認できるまで保存しない運用を条件にする。出典はその場の表示と、自前取得の本文抜粋で作る。
- 利点: Tavily より安い（Mojeek は円換算でより安いが、GBP・カード必須・日本語の質が不明）。固定単価で R／M が単純。独立インデックスで、本文を自前取得する設計と合う。表示は任意。
- リスク: 検索結果を残せないため、**取得元のページが後で消えると出典の本文を再現できない**（その場の表示と、自分の抜粋しか残せない。保存可否は未確認）。URL の保存可否も未確認で、保存権が要るなら Enterprise の個別契約を問い合わせる必要がある。
- 移行: アダプターで隔離するため、後から他社へ替える影響は小さい（設計の前提）。

### B. Mojeek Business

- 料金: £3 / 1,000（税別）。£1 = 200 円の仮で約 0.72 円/検索、月 300 円で約 416 検索（約 138 依頼）。**カード登録が必要**。
- 保存: **無期限の保存権**があり、検索結果をそのまま残せる。表示義務なし。
- 利点: 保存の制約が最も緩い。EU のインフラでサブプロセッサなし。90 日保持で ZDR は相談可。
- リスク: **日本語のインデックスの質が不明**（欧州中心の独立インデックス）。GBP 建てで為替の扱いが要る。Business の保存権は料金ページの説明で、規約本文の裏付けを契約時に確認する必要がある。
- 向く場合: 「検索結果そのものを保存して出典を後から再現したい」ことを優先する場合。

### C. Tavily

- 料金: $0.008/クレジット（basic 1・advanced 2）。basic で約 1.63 円/検索、月 300 円で約 183 検索（約 61 依頼）。毎月 1,000 クレジットの無料枠。
- 保存: 禁止されていない。本文（markdown/text）も返す。
- 利点: 実装が最も短い。本文と日付まで 1 回で返る。レートが高い。
- リスク: **入力と出力を AI の学習に使いうる条項（6.5）**がある。個人アシスタントの検索先として既定にはしにくい。保存を許す代わりに、事業者側の利用が広い。
- 向く場合: 学習利用を許容できる用途に限る。Buddy の既定にはしない。

### D. 保留（B12 を後回しにする）

- 影響: B12-03 以降は始めない。B12-02 も検索サービスの選択を前提にするため、保留の間は契約を確定しない。他の工程（B10・B11・B13・B14）には影響しない。
- 向く場合: 日本語の質を先に測りたい、または保存の扱いを法務的に確認したい場合。ただし実 API の費用と同意が先に要る。

## 8. 未確認・未実施

- **実 API は呼んでいない。** 日本語の検索品質、レイテンシ、実際の応答の形は未測定。
- **実請求は未実施。** 為替は試算用の仮定（170 円/米ドル、£1 = 200 円）で、実際の請求額ではない。
- **法務確認は未実施。** 規約の解釈（特に Brave の「一時的な保存」の範囲、**検索応答に含まれる URL が Search Results に含まれるか**、Mojeek の Business の保存権）は本人または専門家の確認が要る。
- Brave の保存権（Enterprise）への問い合わせはしていない。料金ページの FAQ には「結果を保存できるか」の項目があるが、回答本文は取得できなかった。判断は規約 3.2(i) を根拠にしている。
- Exa は料金（$4 / 1,000 の lite 検索、毎月 $10 の無料クレジット）だけ確認した。規約が PDF で本文を取得できず、**保存条件が不明**のため比較表に入れていない。
- Google Custom Search JSON API は**新規受付を終了**しており、既存の顧客も **2027-01-01 で終了**する（公式ページ）。新規の候補にしない。
- Bing Search APIs は **2025-08-11 で退役**した（公式の告知）。候補にしない。
- Google Search Grounding は、モデル内の検索件数と費用の境界を独立したリクエストとして制御できないため、設計で初期採用しないと決めている。この判断は変えていない。
- 検索結果をスクレイピングで返すサービスは、Google 等の規約に反しうるため候補にしない。
