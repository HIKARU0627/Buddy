# 評価セットの書き出し先

意図判定の評価セットを `IntentEvalCase`（`buddy.eval-case.v1`）の形式で書き出す場所です。形式と変換規則は [ADR 0008](../../docs/adr/0008-memory-forgetting-and-model-evaluation.md)、変換は `scripts/eval-tools.mjs` です。

- 評価セットの本文（発話・正解）は本人のデータを含み得るため、このリポジトリへコミットしません。書き出しは手元の非公開の場所で行います。
- 採否の集計に使えるのは、本人の確認済みで判定用（`judgment`）に分けた例だけです。同じ元例の言い換えは同じ `group_id` にし、調整用と判定用にまたがらせません。
- 正解の引数は `IntentArgs` の項目名に変換します。対応表にないキーや未確認の書き方は変換の失敗にし、その例を集計から除きます。
- メール抽出・返信案・調査・相談／要約・記憶抽出の評価セットの形式は、B10 で用途ごとに作ります。

2026-10-20 時点で評価セットの確認済みは 0 件です。どの用途も評価・採用されていません。
