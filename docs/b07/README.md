`pnpm test` / `pnpm run check` は実行器を自動で含みます。18 ケースを seed `7, 1007, 20261023` で並べ替えて 3 回、計 54 回実行します。seed は、ケースの実行の順序と、同時に受付へ送る要求の順序だけを固定します。予約の ID は予約ごとの連番です（秘密ではない）。

- 期待値は [b07-expectations.json](../../tests/integration/b07-expectations.json) に手書きします。合成の通貨 XTS・縮めた上限（total 200・llm 100・llm.background 50・search 40・voice 50・overage 60）・M = 入力 10 + 出力の上限 30 = 40・会話は 1 秒 1 単位（最低 15・上限 60）から、設計 05・09 と ADR の規則で手計算した値で、domain・DB worker・予算の門の処理から作っていません。枠の上限と経路の表は手書きで、試験の合成の設定との一致を毎回確かめます。
- 突き合わせの規則は `findings`（`tests/integration/b07-support.mjs`）です。予約の行は SQL で直接読み、provider の受信（request_id・予約）と provider 自身の真の usage を使い、(1) 同じ要求を二度受信しない、(2) 受信は送出意図のある予約だけで予約の取り違えがない、(3) 送出意図があって受信のない予約は usage 不明だけ、(4) provider の usage で精算した予約の実費は provider の真の usage と同じ、(5) 照合 ID の使い回しがない、(6) 送出意図または受信のある予約が解放（released）になっていない、(7) 枠・予算月ごとの使用量（精算済みは実費、未精算は M、解放は 0）が上限以内、を確かめます。同時の受付（`wave`）では、精算の前に受付の命令がそろうので、M の合計も上限以内であることを確かめます。この規則自体が、上限の超過・二重の受信・取り違え・実費の食い違い・照合 ID の使い回し・送った予約の解放を検出できることは `b07-support.test.mjs` で、手で作った不正な記録を使って確かめます。
- 実行器の感度は、製品のコードに一時的に欠陥を入れて確かめました（コミットしていません）。受付の M の上限の判定を 1 ずらすと X18・X53 が、usage 不明のときに provider へ送り直すようにすると 19 件が失敗しました。
- 競合の勝ち負けは命令の並びで決まるので、X18 の境界の同時の予約と追加予約の競合は、ケースの並べ替えに任せず、投入順の両方（c → d と d → c、v1 → v2 と v2 → v1）を明示して実行し、投入した順序もケースの観測に記録して検査します（証拠の予約の行で、勝つ予約が順序で入れ替わることを確認済み）。
- 待ち合わせは、関門（`barrier`）・provider の受信の知らせ・手で発火する timer と手で進める時計で行い、固定の sleep を使いません。受付の命令は、すべての要求が関門に着いてから DB worker へ送ります。
- 模擬の有料 provider と予算の門・DB worker は同じプロセスで、HTTP の経路（B07-05）は通しません。再起動は DB worker だけを閉じて開き直す模擬で、OS の電源断や実機の試験ではありません。
- 設定ファイルの権限（他人が書ける設定の拒否）は POSIX だけで確かめ、Windows では期待値から外します。

記録は [evidence-b07-simulated.json](../../tests/integration/evidence-b07-simulated.json)、実施状態は [test-map.json](../../tests/test-map.json) です。`kind: simulated` の記録で、`records` はケース別の結果、`runs` は各 seed の実際の順序・手書きの期待値と一致した観測（結果・利用状況・予約の行・provider の受信）です。`commit` は実行時の基点コミットで、未コミットの差分を含む検査対象は `source_sha256` で特定します。`scripts/test-map.test.mjs` が現行ソースの対象一覧と hash の完全一致、観測と手書きの期待値の一致、対応表の範囲を検査します。これを基点コミットだけの試験結果と読み替えないでください。

`source_sha256` の対象の決め方（[scripts/b07-evidence-sources.mjs](../../scripts/b07-evidence-sources.mjs)。集め方は B04 と共通の [scripts/evidence-sources.mjs](../../scripts/evidence-sources.mjs)）:
